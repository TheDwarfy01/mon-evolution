Aucun fichier de sauvegarde relié.

La première fois, choisis Google Drive comme destination. Les modifications suivantes seront enregistrées automatiquement dans ce fichier. Google Drive synchronisera les changements lorsque le téléphone sera connecté.

Pour supprimer un profil uniquement sur Drive, utilise le bouton situé dans Modifier le profil. L'application demandera une double confirmation.

Le chargement remplace les profils présents après confirmation. Une même sauvegarde ouverte sur plusieurs téléphones ne se fusionne pas automatiquement : le dernier enregistrement peut remplacer l'autre.
