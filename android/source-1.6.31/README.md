# Mon Évolution IMC — sources Android v1.6.31

Ce dossier contient **l'intégralité des sources Android v1.6.31**,
reconstruites à partir de `android/source-1.6.5` et des correctifs successifs
dans `android/patches/`. Elles correspondent à l'APK publié sous
[v1.6.31](https://github.com/TheDwarfy01/mon-evolution/releases/tag/v1.6.31).

Point de départ conseillé pour toutes les nouvelles modifications :
`android/source-1.6.31/`. Ce dossier peut être ouvert directement
comme projet Android (Gradle). Pour compiler, utiliser JDK 17 et un
environnement Android SDK avec la plateforme Android 35.

Ne pas publier de clés de signature, mots de passe, profils privés ou
fichiers `local.properties`. La signature des APK officiels est gérée
par les secrets de GitHub Actions, hors de ce dossier.
