MON ÉVOLUTION — SITE GITHUB PAGES

1. Ouvre https://github.com/TheDwarfy01/mon-evolution
2. Add file > Upload files.
3. Dépose index.html, confidentialite.html, conditions.html, style.css et logo.png directement à la racine du dépôt.
4. Clique Commit changes.
5. Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
6. Après publication, le site devrait être accessible à : https://thedwarfy01.github.io/mon-evolution/
   Les autres pages devraient être :
   https://thedwarfy01.github.io/mon-evolution/confidentialite.html
   https://thedwarfy01.github.io/mon-evolution/conditions.html
7. Avant publication OAuth en production, remplacer les paragraphes de contact génériques par une adresse de contact publique et vérifier les mentions selon le fonctionnement réel de la version finale.
8. Vérifier la compatibilité de ces URLs avec les exigences Google OAuth de vérification du domaine. Un domaine GitHub Pages partagé pourrait nécessiter un domaine personnalisé dont la propriété est vérifiable.
